## 📖 프로젝트 소개

플레이어는 대장장이가 되어 무기를 제작·강화하고, 20단계까지 무기를 강화하는것이 게임의 목표입니다.

- **강화 시스템**: 슬롯 머신을 누르듯 강화 버튼을 누르고, 성공과 실패를 나눔
- **미니 게임**: 강화를 시작할 때 일정 확률로 발생하는 이벤트. 결과에 따라 강화 확률이 달라진다.
- **업적 시스템**: 게임을 진행하며 특수한 상황에서 업적을 달성, 특수한 보상을 얻을 수 있다.
- **성장 요소**: 업적, 재화, 상점을 통한 대장간 확장을 통해 더 값 비싼 검을 얻을 수 있게된다.

1인 개발 · Unity 6 LTS 기반 · WebGL/모바일 타겟
